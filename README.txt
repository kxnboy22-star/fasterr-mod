faster! - Minecraft 1.21.11 Fabric mod (client-side)
Keybind: FASTER FASTER FASTER (default V). Tap = one swap-jab. Hold = keeps lunging.
Needs a Lunge I-III spear in your hotbar. Hold something else (e.g. a golden apple), press V.
Set ATTRIBUTE_SWAP = false in FasterClient.java for servers that block attribute swapping.
